# Spacebattle — асинхронный движок космического боя

Учебный проект по архитектуре ПО: серверная симуляция космического боя на C#/.NET,
построенная вокруг паттернов Command и Strategy, самописного IoC-контейнера
и асинхронной обработки команд через очередь.

## Архитектура

- **Spacebattle.Lib** — доменная логика:
  - *Commands* — команды перемещения, поворота, проверки столкновений,
    старт/стоп долгих операций, `MacroCommand` для композиции команд по зависимостям
  - *Strategies* — создание игры, обработка коллизий, дефолтный обработчик сообщений
  - *Entities* — `Vector`, `Angle`, `ServerThread` (поток с `BlockingCollection`-очередью)
  - *Abstractions* — `ICommand`, `IQueue`, `IRotatable`, `IStrategy`, `IUObject`
- **Spacebattle.Server** — Web API-слой на CoreWCF/Kestrel: принимает сообщения
  от клиента и превращает их в команды через IoC-резолвинг
- **Spacebattle.Tests** — xUnit + Moq, покрытие через coverlet

## Как это работает

Каждый игровой тик выполняется в отдельном потоке: команды складываются в очередь,
и `GameCommand` разбирает их с ограничением по времени (time quantum). Все зависимости
резолвятся через IoC-контейнер (`Hwdtech.IoC`) вместо прямого создания объектов —
это позволяет подменять реализации команд/стратегий без изменения кода, который их вызывает.
